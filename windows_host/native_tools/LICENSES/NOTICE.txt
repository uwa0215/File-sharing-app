DeviceBridge Third-Party Sidecar Notices

DeviceBridge invokes the following unmodified external sidecar executables via
process execution (dart:io Process.start) in <install_dir>\tools\:

1. Android Debug Bridge (adb.exe) — Android SDK Platform-Tools (Apache-2.0)
2. scrcpy (scrcpy.exe / scrcpy-server) — Genymobile (Apache-2.0); bundles
   FFmpeg / SDL2 / libusb dynamic libraries under their respective LGPL/GPL/zlib licenses.
3. libimobiledevice / iproxy (iproxy.exe + libimobiledevice/libusbmuxd/libplist)
   — LGPL-2.1+. Kept as dynamically linked sidecar binaries so users may replace
   or upgrade the DLLs/executables independently.
4. UxPlay (uxplay.exe, optional AirPlay 2 receiver) — GPL-3.0+.

Keep original license texts alongside any redistributed sidecar binaries.
